# IC Library

面向集成电路学习与科研的资源导航与论文配图参考网站。IC Library 整理课程、工具、开源项目和研究资源；其中的 IC Gallery 提供论文图片浏览与检索，帮助读者寻找科研表达的灵感。

## 功能

- 按用途、研究方向或关键词查找学习与科研资源。
- 在 IC Gallery 中按来源、年份、模式和关键词浏览图片；支持通过 `#编号` 精确搜索。
- 画廊支持中文／英文、深色／浅色主题，以及像素小猫叭噗和彩蛋互动。
- 收集进度、主题偏好等保存在当前浏览器中，不提供跨设备同步；清除浏览器站点数据可能会重置进度。

Gallery 的分类和内容仍在完善中，图片分类暂未完成准确的人工核对。文生图功能正在迁移，当前版本不提供该功能。

## 本地预览

这是一个静态网站，无需后端或数据库。在本目录运行：

```bash
python -m http.server 8765
```

然后在浏览器中打开 `http://localhost:8765/`。部署时将本目录作为静态网站根目录。
